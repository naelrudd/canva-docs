# Merges

The Canva Connect APIs for merging data into designs.

## Merge APIs

* [Create merge](https://www.canva.dev/docs/connect/api-reference/merges/create-merge/): Merge data into a template design.
* [Get merge](https://www.canva.dev/docs/connect/api-reference/merges/get-merge/): Get the status of a merge job.
