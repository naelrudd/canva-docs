# Users

The Canva Connect APIs for retrieving user information.

## Users APIs

* [Get user](https://www.canva.dev/docs/connect/api-reference/users/get-user/): Get the current user's profile.
* [Get user's team profile](https://www.canva.dev/docs/connect/api-reference/users/get-users-team-profile/): Get the user's team profile.
* [List user's designs](https://www.canva.dev/docs/connect/api-reference/users/list-users-designs/): List the current user's designs.
