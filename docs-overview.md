# Canva Developers Documentation Overview

Source: https://www.canva.dev/docs/

Canva Developers provides tools and APIs to extend Canva for 240M+ users.

## Documentation Sections

- **[Apps SDK](/docs/apps/)** — Build inside Canva using the Apps SDK to bring new design and editing experiences into the Canva editor.
- **[Connect APIs](/docs/connect/)** — Add Canva to your product using the Connect APIs to integrate Canva capabilities into your platform.
- **[MCP](/docs/mcp/)** — Model Context Protocol for AI assistant integration.
- **[SCIM API](/docs/scim/)** — Automate Canva user account provisioning.
- **[Audit Logs](/docs/audit-logs/)** — Track changes made by your team in Canva.
- **[Flourish Charts](/opensource/flourish-charts/)** — Turn data into interactive visual stories.

## Capabilities

- **Add design tools** — Build apps with custom editing tools, visual effects, or AI features. [/docs/apps/intents/design-editor/]
- **Embed Canva** — Integrate Canva into any platform. [/docs/connect/]
- **Connect to data sources** — Import data from third-party sources for design generation or Bulk create. [/docs/apps/intents/data-connector/]
- **Autofill designs** — Personalize Brand Templates with real-time content. [/docs/connect/autofill-guide/]
- **Publish instantly** — Send designs to third-party platforms. [/docs/apps/intents/content-publisher/]
- **Manage Brand Templates** — Make Brand Templates accessible. [/docs/connect/api-reference/brand-templates/]
- **Bulk create** — Generate personalized content in bulk. [/docs/connect/autofill-guide/]
- **Design interaction** — Inspect, modify, and manage designs. [/docs/apps/examples/]
- **Resize designs** — Create resized versions in new dimensions. [/docs/connect/api-reference/resizes/]
- **Reply to comments** — Receive and reply to Canva comments. [/docs/connect/api-reference/comments/]
- **Expand URLs** — Bring content into Canva AI via links. [/docs/apps/intents/url-expander/]
