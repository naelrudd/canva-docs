# Figma resource

Mock up designs for your app.

Introducing our Figma resource! This Figma file includes the common Canva components you may need to mock up a design for your app.

## How to use this file

1. Download and install font files (Canva Sans and Canva Sans Display).
2. Download the Figma resource file and open it in Figma.
