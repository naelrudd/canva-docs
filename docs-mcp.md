# Canva Model Context Protocol (MCP)

Source: https://www.canva.dev/docs/mcp/

Connect AI assistants to Canva's design capabilities via the Model Context Protocol.

## Capabilities

- **Design generation** - Create designs from text descriptions
- **Design editing** - Modify existing designs via natural language
- **Design discovery** - Search and retrieve designs, pages, and folders
- **Asset and brand management** - Upload assets, manage folders, access brand kits
- **Design export** - Export in PDF, PNG, JPG, PPTX, MP4, etc.
- **Collaborative workflows** - Add comments and feedback loops

## Getting Started

1. Register your redirect URI (via waitlist)
2. Configure your AI assistant with `https://mcp.canva.com/mcp`
3. Set up the connection (each user authenticates individually)
4. Test the connection

## Authentication

Dynamic Client Registration (DCR) is recommended.

## Plan Availability

- **All plans**: Core features
