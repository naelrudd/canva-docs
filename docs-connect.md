# Canva Connect APIs

Source: https://www.canva.dev/docs/connect/

The Canva Connect APIs let you integrate Canva's capabilities into your own web apps and platforms.

## Features

- Create and sync assets, designs, comments, and more
- Collaborate and communicate with different platforms
- Embed Canva into project management workflows

## Public vs. Private

- **Public integrations** available to all Canva users (must pass review)
- **Private integrations** available only to your team on Canva Enterprise
