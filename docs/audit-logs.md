# Canva Audit Logs

Source: https://www.canva.dev/docs/audit-logs/

Track changes made by your team in Canva. Available for Canva Enterprise organizations.

- Stored in an AWS S3 bucket that your organization owns
- Events added every minute as gzipped JSONL archives
- Each activity recorded as an audit event with an `action` property
