# Resizes

The Canva Connect APIs for resizing designs.

## Resize APIs

* [Create resize](https://www.canva.dev/docs/connect/api-reference/resizes/create-resize/): Resize a design into new formats.
* [Get resize](https://www.canva.dev/docs/connect/api-reference/resizes/get-resize/): Get resize job status.
