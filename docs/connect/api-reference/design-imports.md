# Design import

The Canva Connect APIs for importing designs from other applications into Canva.

## Supported file types

Adobe Illustrator (.ai), Adobe Photoshop (.psd), Affinity (.af/.afdesign/.afphoto/.afpub), Apple Keynote (.key), Apple Numbers (.numbers), Apple Pages (.pages), Microsoft Excel (.xls/.xlsx), Microsoft PowerPoint (.ppt/.pptx), Microsoft Word (.doc/.docx), OpenOffice Draw/ Presentation/Sheets/Text (.odg/.odp/.ods/.odt), PDF (.pdf).

## Design import APIs

* [Create design import job](https://www.canva.dev/docs/connect/api-reference/design-imports/create-design-import-job/): Import a file as a new design.
* [Create URL import job](https://www.canva.dev/docs/connect/api-reference/design-imports/create-url-import-job/): Import from a URL.
* [Get design import job](https://www.canva.dev/docs/connect/api-reference/design-imports/get-design-import-job/): Get job status and results.
* [Get URL import job](https://www.canva.dev/docs/connect/api-reference/design-imports/get-url-import-job/): Get URL import job status and results.
