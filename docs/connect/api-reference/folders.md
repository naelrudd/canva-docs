# Folders

The Canva Connect APIs for managing folders in a user's Canva library.

The top level is represented by folder ID `root`. The Uploads folder is `uploads`.

## Folders APIs

* [Create folder](https://www.canva.dev/docs/connect/api-reference/folders/create-folder/): Create a new folder.
* [Get folder](https://www.canva.dev/docs/connect/api-reference/folders/get-folder/): Retrieve folder metadata.
* [Update folder](https://www.canva.dev/docs/connect/api-reference/folders/update-folder/): Update folder metadata.
* [Delete folder](https://www.canva.dev/docs/connect/api-reference/folders/delete-folder/): Delete a folder.
* [List folder items](https://www.canva.dev/docs/connect/api-reference/folders/list-folder-items/): List folder contents.
* [Move folder item](https://www.canva.dev/docs/connect/api-reference/folders/move-folder-item/): Move an item between folders.
