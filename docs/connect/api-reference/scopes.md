# Scopes

OAuth 2.0 scopes for Canva Connect API authorization.

## Available scopes

- `design:content:read` - Read design content (export, pages, fields)
- `design:content:write` - Create, update, import, merge, and resize designs
- `design:meta:read` - Read design metadata
- `folder:read` - Read folder contents
- `folder:write` - Create, update, and delete folders
- `user:read` - Read user profile
- `team:read` - Read team profile
- `webhook:read` - Read webhook subscriptions
- `webhook:write` - Create and delete webhook subscriptions
- `comment:read` - Read comments
- `comment:write` - Create and resolve comments
- `asset:read` - Read uploaded assets
- `asset:write` - Upload assets
