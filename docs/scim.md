# Canva SCIM API

Source: https://www.canva.dev/docs/scim/

Use the SCIM API (System for Cross-domain Identity Management) to automate provisioning of Canva user accounts.

- Endpoint: `https://www.canva.com/_scim/v2`
- Implements SCIM v2 specification
- Case-sensitive parameters
- Available for Canva Enterprise (single team)
