# Written content guidelines

Learn how to craft effective written content for your app listing.

## App name

* Don't begin your app's name with "**Magic**".
* Don't include the words "**Canva**" or "**Pro**" anywhere in the name.
* Keep the name under 10 characters.
* Make sure the name is unique.
* Don't use emojis.

## Short description

* Avoid acronyms, initialisms, abbreviations, slang, and jokes.
* Write in plain text without line breaks.
* Use sentence case.
* Don't use emojis.

## Tagline

* Describe what the app does, not what's great about the app.
* Don't include marketing claims.
* Use sentence case.
* Don't use emojis.

## Description

* Use "design" to describe what a user is creating in Canva.
* End sentences with punctuation.
* Write in plain text without line breaks.
* Don't include marketing claims.
* Use sentence case.
* Don't use emojis.
