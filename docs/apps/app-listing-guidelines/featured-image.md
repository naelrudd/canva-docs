# Featured image guidelines

Learn how to visually represent the functionality of your app.

* **Maximum of 2 images** in a carousel.
* **2400 x 1800 pixels** with a 4:3 aspect ratio.

NOTE: Only use content that you have the rights to use.

## Style selection

Three options:
- **Editorial**: Bold, graphic aesthetic focusing on the final product.
- **Contextual**: Showcasing the app in action within Canva.
- **2x featured image viewed in a carousel (Editorial + Contextual)**

## Do

- DO add only a few elements to make it bigger and clearer
- DO ensure the object panel is the right color
- DO keep text to a minimum
- DO opt for simple and bold scaling/cropping
- DO use Canva's colors in harmonious sets
- DO use the featured image to highlight your app's hero feature
- DO display content that captivates potential users
- DO showcase accurate UI

## Don't

- DON'T put too many elements in the thumbnail
- DON'T use non-harmonious Canva colors
- DON'T crop the focal point in split screen
- DON'T abstract the UI by layering floating elements
- DON'T oversimplify the UI
- DON'T add written content unless crucial
- DON'T alter or deconstruct the UI
- DON'T show the whole browser or Canva UI
