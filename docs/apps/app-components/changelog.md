# Changelog

The latest changes to the App Components.

## 2.5.0 - 2026-05-15
- Added `search.requireQuery` option to `Config`.

## 2.4.0 - 2026-04-20
- Updated `OauthAccountSwitcher` so `onAccountSwitch` receives `null` when there is no active account.

## 2.3.0 - 2026-04-02
- Added `AccountSwitcher` and `OauthAccountSwitcher` composite components.

## 2.2.0 - 2026-03-16
- Bumped peer dependency @canva/app-ui-kit to ^5.7.0

## 2.1.0 - 2025-10-20
- Fixed hover styling for item cards.
- Upgraded `@canva/app-ui-kit` to 5.1.0, react to ^19.2.0.

## 2.0.0 - 2025-10-01
- Upgraded `@canva/app-ui-kit` to version 5, react to ^19.0.0.

## 1.3.1 - 2025-07-24
- Upgraded `@canva/design` to ^2.7.0, `@canva/platform` to ^2.2.0.

## 1.3.0 - 2025-04-22
- Added `thumbnailCorsCheck` option to `Config`.

## 1.2.0 - 2025-03-24
- Fixed image/video thumbnail overflow in list layout.
- Upgraded `@canva/app-ui-kit` to 4.8.0.

## 1.1.0 - 2024-12-02
- Added file size handling for assets exceeding SDK limits.

## 1.0.0 - 2024-11-25
- Added translation (i18n) system to `SearchableListView`.

## 1.0.0-beta.32 - 2024-10-31
- Exported `Thumbnail` type.

## 1.0.0-beta.30 - 2024-10-24
- Excluded "application/json" from `VideoMimeType`.
- Added `access` field to `Container`.

## 1.0.0-beta.29 - 2024-10-03
- Added `export.requireContainerSelected` field for `Config`.

## 1.0.0-beta.28 - 2024-09-24
- Updated acceptedFileTypes to lowercase for @canva/asset v2 compatibility.

## 1.0.0-beta.26 - 2024-09-19
- Added CORS check for thumbnails.

(Full changelog continues with earlier beta versions.)
