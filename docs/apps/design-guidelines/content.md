# Content

Guidelines for importing and using content in Canva.

* All media must adhere to Canva's [Acceptable Use Policy](https://www.canva.com/policies/acceptable-use-policy).
* Users must initiate media uploads. Do not upload media without explicit permission and intent.
* Thumbnails must have the same aspect ratio as the full-size media.
* Thumbnails must be an accurate representation of the full-size media.
