# Suspension

How apps should behave in a suspended state.

Apps can be [suspended](https://www.canva.dev/docs/apps/suspension/). This mimics the native user experience of Canva, but it also introduces the risk of confusing behavior, as apps can continue to perform certain actions while it's not visible.

To ensure a straightfoward user experience, apps in a suspended state must not:

* Perform operations that require user interaction, like uploading assets or adding elements to a design
* Access any user data
