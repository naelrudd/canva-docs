# Drag and Drop

Guidelines for using the Drag and Drop capability.

* Users should be able to click on the media's thumbnail to add it to a design.
* Media dropped into the design should be high-resolution, clear, and not pixelated.
* Use the same aspect ratio for each representation of the same media — this includes thumbnails, preview media, and full-resolution media.
* While media is being dragged into a design, temporarily hide the media's thumbnail to create the effect of the media being moved, consistent with the native Canva experience.
