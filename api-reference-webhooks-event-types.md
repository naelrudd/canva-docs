# Event types

Webhook event types for subscribing to Canva Connect events.

## Event types

- `design.created` - A design is created
- `design.updated` - A design is updated
- `design.deleted` - A design is deleted
- `design.comment.created` - A comment is created on a design
- `design.mentioned` - The user is mentioned in a design
- `design.published` - A design is published
- `design.republished` - A design is republished
- `design.unpublished` - A design is unpublished
- `comment.resolved` - A comment is resolved
- `comment.unresolved` - A comment is unresolved
