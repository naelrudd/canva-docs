# Designs

The Canva Connect APIs for managing designs. The `designs` endpoint lets you interact with the designs present in a user's content library.

## Designs APIs

* [Create design](https://www.canva.dev/docs/connect/api-reference/designs/create-design/): Create a new Canva design.
* [List designs](https://www.canva.dev/docs/connect/api-reference/designs/list-designs/): List all the user's designs.
* [Get design](https://www.canva.dev/docs/connect/api-reference/designs/get-design/): Get the metadata for one of the user's designs.
* [Get design pages](https://www.canva.dev/docs/connect/api-reference/designs/get-design-pages/): Get the metadata for pages in a design.
* [Get design export formats](https://www.canva.dev/docs/connect/api-reference/designs/get-design-export-formats/): Get the export formats available for a design.
