# Unit test

Unit testing Apps SDK packages.

## Running this example

1. Create a new app in the [Developer Portal](https://www.canva.com/developers/apps). See [Quickstart guide](https://www.canva.dev/docs/apps/quickstart/).
2. Set "Development URL" to `http://localhost:8080`.
3. Clone the starter kit: `git clone https://github.com/canva-sdks/canva-apps-sdk-starter-kit.git && cd canva-apps-sdk-starter-kit`
4. Install dependencies: `npm install`
5. Run the example: `npm run start unit_test`
6. Click **Preview URL** to open in Canva editor.
