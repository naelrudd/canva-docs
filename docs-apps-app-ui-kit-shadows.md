# Shadows

An overview of shadows in the App UI Kit.

The App UI Kit exposes [design tokens](https://www.canva.dev/docs/apps/app-ui-kit/design-tokens/) for shadows. These shadows add subtle elevation to a component, which is mostly noticeable with the light theme, as they blend in with the app's background on a dark theme.
