# Analytics

How to track the discovery and usage of an app.

## Viewing analytics

You can find the analytics for an app in the Developer Portal on the app's **Analytics** page.

## What Canva tracks

* **App listing views**: When a user views an app's installation screen in the Canva editor.
* **App installations**: When a user clicks the **Open** button on an app's installation screen.
* **App usage**: How many unique users are using an app.

## Interpreting the data

The analytics page shows:
* Total number of app listing views by unique users over the last 30 days.
* Percentage change between the last two data points.
* Cumulative growth over the last 30 days.

## Limitations

* Apps can't track analytics with third-party software due to the Content Security Policy.
