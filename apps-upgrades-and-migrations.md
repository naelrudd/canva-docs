# Upgrades and migrations

Keep your app up to date with the latest Canva features and best practices.

## Available migrations

* **[Apps SDK v2](https://www.canva.dev/docs/apps/upgrades-and-migrations/v2-migration-guide/)**: Migrate from Apps SDK v1 to v2.
* **[Design Editor intent](https://www.canva.dev/docs/apps/upgrades-and-migrations/design-editor-migration-guide/)**: Migrate from legacy direct render to Design Editor intent.
* **[App UI Kit v5](https://www.canva.dev/docs/apps/upgrades-and-migrations/app-ui-kit-v5-migration/)**: Migrate from App UI Kit v4 to v5.

## Automated migrations with the Canva CLI

```shell
canva apps migrate <migrationName>
```

### Example

```shell
canva apps migrate apps-sdk-v1-v2
```
