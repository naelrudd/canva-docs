# Set up payout details

Receiving payments from Canva's monetization programs.

Canva's [Premium Apps Program](https://www.canva.com/developers/premium-apps-program/) is a monetization program for app developers.

To set up payout details for an app:

1. Navigate to the [Your apps](https://www.canva.com/developers/apps) page.
2. Select the app you're configuring payout details for.
3. Navigate to the **Monetization** tab.
4. Click **Add or edit payout method**.
5. In the **Details** tab of the **Payments** page, enter your payout details.

**Warning:** If you're creating an app as a member of a team, you must be an administrator of that team to set up payout details.
