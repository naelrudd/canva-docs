# Premium Apps Program

Monetizing apps with the Premium Apps Program.

Do you have a great app or an idea for one, and want to earn some revenue from Canva? The [Premium Apps Program](https://www.canva.com/developers/premium-apps-program/) is how you partner with Canva to bring it to our community.

Apps can be:

* **Gated** - All of your app's features are only available with paid Canva plans.
* **Freemium** - Your app's core features are available with Canva Free. Premium features come with paid plans.
* **Credit-based** - Your app provides a starter quota of credit. When the starter credit runs out, premium features are unlocked by upgrading.

Here's how it works:

1. You specify certain features of your app to be billable actions.
2. You offer different levels of feature access based on a user's Canva plan.
3. Canva compensates you for the usage of those features.

## User experience

1. The user opens the app.
2. The app checks if the user has a free or paid Canva plan.
3. The user sees that certain premium features require a paid Canva plan.
4. The user attempts to access a premium feature.
5. If the user has a free Canva plan, a dialog for upgrading opens.
6. If the user has a paid Canva plan, the app performs the billable action and Canva tracks usage.
